# Overlay calibration

Functional direction/stance-label templates calibrated from public Anna Season 3 guide frames:

- RyzingSol: https://www.youtube.com/watch?v=IKaAPbrhZxo (Guaranteed Follow-ups section).
- TheFURY: https://www.youtube.com/watch?v=HKGx3Syazxw (Counter Hit section).

These small interface glyphs are used for local image matching. They do not establish complete guide extraction. RyzingSol's bottom four-dot layout and TheFURY's top four-dot layout have different spacing and button palettes. The direct visual reader provides an explicitly unverified draft; strings, timing, holds, whiffs, unsupported/new stance labels and layout changes require review. Whole frames/video are not included or published. Other layouts may need calibration.
